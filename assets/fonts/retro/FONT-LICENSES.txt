LOCAL USE
Define @font-face rules that reference these local files. No Google Fonts CSS, remote font CDN, or runtime network request is required for these fonts.
Current UI usage: Pixelify Sans for headings, Chakra Petch at weight 400 for
body copy, 500 for medium emphasis and 600/700 for bold. Font sizes and line
heights remain unchanged. Small technical labels use the system monospace stack.
Keep all OFL files with any redistributed website package. Font licensing applies to the fonts; it does not replace the website code license.

VALIDATION
TrueType signature, complete FontTools table decoding, weight axis and Latin cmap checked for Pixelify Sans. WOFF2 signature and declared byte length checked, and both IBM Plex fonts successfully parsed through Fontconfig/FreeType with the expected family and style. Both original license files contain SIL OFL 1.1.
